# STUDENIQU

אפליקציה מתוכננת לתמיכה בסטודנטים בניהול מטלות אקדמיות ותכנון למידה: ניהול משימות ומועדי הגשה, ותוכנית למידה יומית או שבועית שסוכן AI מציע והסטודנט מאשר.

**צוות הפרויקט:** אחמד מחאמיד | אדיאן נוגידאת | גיזאל גודי

**סטטוס:** פרויקט אקדמי בשלב אפיון. עדיין אין קוד.

## מסמכים

- [מסמך אפיון מוצר (1 בנובמבר 2026)](docs/SPEC.md): מעודכן להערות יונתן מ-31.10.2026.

## יכולות ליבה ב-MVP

1. ניהול משימות ומועדי הגשה
2. תכנון למידה באמצעות AI (הצעה, שינוי דרך צ׳אט, אישור לפני שמירה)

יכולות MVP נוספות, ללא דירוג פנימי: מערכת שעות והרצאות; ייבוא מידע ומסמכים; Dashboard וגרפי התקדמות.

## מדד הצלחה

לפחות 40% חיסכון בזמן תכנון הלמידה לעומת תכנון ידני (יעד עתידי, לא תוצאה מדודה).
