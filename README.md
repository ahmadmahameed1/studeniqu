# STUDENIQU

מערכת לניהול למידה אקדמית לסטודנטים: מערכת שעות, משימות ומועדי הגשה, תוכנית למידה שבועית שה-AI מציע והסטודנט מאשר, ומדדי התקדמות.

**סטטוס:** שלב אפיון (פרויקט אקדמי). עדיין אין קוד.

## מסמכים

- [מסמך אפיון מוצר, גרסה 1.1](docs/SPEC.md): מעודכן לפי הערות המנחה מ-31.10.2026.

## יכולות ה-MVP לפי עדיפות

1. ניהול משימות ומועדי הגשה (כולל תת-משימות)
2. תכנון למידה באמצעות AI (הצעה לאישור הסטודנט)
3. מערכת שעות והרצאות
4. Dashboard וגרפי התקדמות
5. ייבוא מידע ומסמכים
