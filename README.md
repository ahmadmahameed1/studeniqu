# STUDENIQU

אפליקציה לתמיכה בסטודנטים בניהול מטלות אקדמיות ותכנון למידה: ניהול משימות ומועדי הגשה, ותוכנית למידה יומית או שבועית שהמערכת מציעה והסטודנט מאשר.

**צוות הפרויקט:** אחמד מחאמיד | אדיאן נוגידאת | גיזאל גודי

**סטטוס:** פרויקט אקדמי. קיימת גרסה עובדת ראשונה של שתי יכולות הליבה.

## צפייה באפליקציה

**אונליין:** https://ahmadmahameed1.github.io/studeniqu/ (GitHub Pages, מציג את הענף `main`).

שם לוחצים "טעינת נתוני דוגמה", ואחר כך "הצע תוכנית" ו"אישור ושמירה", כדי לראות את התוכנית ואת הגרפים.

## הרצה במחשב

אין צורך בהתקנה. פותחים את `index.html` בדפדפן (Chrome, Edge או Firefox).

## תהליך עבודה בענפים

`feature/*` ← Pull Request ל-`dev` ← Pull Request מ-`dev` ל-`main`. הענף `main` הוא הגרסה היציבה, ומה שבו מוצג ב-GitHub Pages.

הבדיקות: פותחים את `tests/tests.html`. אם הדפדפן חוסם קבצים מקומיים, מריצים שרת סטטי מתיקיית הפרויקט ופותחים את הכתובת שלו.

## מה עובד בגרסה הזו

- **משימות ומועדי הגשה:** הוספה, עריכה ומחיקה; קורס, מועד ומשך משוער; סטטוס (לביצוע / בתהליך / הושלם); תתי-משימות; סימון משימות באיחור; ספירה לאחור עד מועד ההגשה ("היום", "מחר", "בעוד 3 ימים", "באיחור של 2 ימים").
- **תכנון למידה:** הצעת תוכנית יומית או שבועית לפי המועדים והזמינות; התראה על עומס והצעות לפתרון; שינוי ההצעה דרך צ׳אט (למשל "בלי יום שישי"); שמירה רק אחרי אישור; הצעה לתכנון מחדש כשמקטע שתוכנן עבר והמשימה לא הושלמה.
- **זמינות:** שעות פנויות לכל יום בשבוע.
- **סיכום:** משימות להיום, משימות באיחור, שעות בתוכנית המאושרת.
- **נתונים:** טעינת נתוני דוגמה בלחיצה, ייצוא כל הנתונים לקובץ JSON וייבוא שלהם בחזרה.
- **גרפים (ניסיוני):** שעות מתוכננות לפי יום מול שעות פנויות, משימות לפי סטטוס, ושעות שנותרו לפי קורס. אפשר להסתיר את הגרפים או להציג אותם כטבלה.

**חשוב:** סוכן התכנון בגרסה הזו הוא אלגוריתם מקומי ולא מודל AI. הנתונים נשמרים רק בדפדפן. פרטים ב-[docs/PLAN.md](docs/PLAN.md).

## מבנה הפרויקט

| נתיב | תוכן |
|---|---|
| `index.html`, `css/style.css` | ממשק המשתמש (עברית, RTL) |
| `js/planner.js` | אלגוריתם התכנון |

| `data/` | נתוני דוגמה, מבנה הנתונים (`schema.json`) והסבר ([data/README.md](data/README.md)) |

| `docs/SPEC.md` | מסמך האפיון (1 בנובמבר 2026) |
| `docs/PLAN.md` | תוכנית המימוש |
