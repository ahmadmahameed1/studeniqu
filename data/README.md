# נתונים (data)

התיקייה מתארת את הנתונים של STUDENIQU וכוללת נתוני דוגמה להדגמה.

## קבצים

| קובץ | תוכן |
|---|---|
| `sample-data.js` | נתוני דוגמה: סטודנטית שנה ב׳ עם 5 קורסים ושבוע עמוס. נטענים בכפתור "טעינת נתוני דוגמה". |
| `schema.json` | מבנה קובץ הנתונים (JSON Schema) שהאפליקציה מייצאת ומייבאת. |

## איפה הנתונים נשמרים

בגרסה הנוכחית הנתונים נשמרים בדפדפן (`localStorage`, במפתח `studeniqu.v1`). אין שרת ואין מסד נתונים בענן. כדי להעביר נתונים בין מחשבים משתמשים ב"ייצוא נתונים" וב"ייבוא נתונים".

## מבנה הנתונים

### משימה (task)

| שדה | סוג | הסבר |
|---|---|---|
| `id` | טקסט | מזהה ייחודי |
| `title` | טקסט | כותרת המשימה |
| `course` | טקסט | שם הקורס (לא חובה) |
| `due` | תאריך `YYYY-MM-DD` | מועד ההגשה |
| `estHours` | מספר או `null` | משך משוער בשעות; `null` = חסר משך, והמשימה לא נכנסת לתוכנית |
| `status` | `todo` / `doing` / `done` | לביצוע / בתהליך / הושלם |
| `subtasks` | רשימה של `{title, done}` | תתי-משימות; משפיעות על השעות שנותרו |

### זמינות (availability)

שעות פנויות ללמידה לכל יום בשבוע: מפתחות `0` עד `6`, כש-`0` הוא יום ראשון.

### תוכנית מאושרת (approvedPlan)

התוכנית האחרונה שהסטודנט אישר: סוג (`day` / `week`), תאריך התחלה, ולכל יום את הקיבולת ואת מקטעי הלמידה (`taskId`, `title`, `hours`). תוכנית מוצעת שלא אושרה לא נשמרת.

## נתוני הדוגמה

בנתוני הדוגמה התאריכים יחסיים להיום (`dueInDays`), כך שהם תמיד מתאימים לשבוע הנוכחי. הם כוללים משימה באיחור, משימה שהושלמה, משימה בלי משך משוער, ומשימות עם תתי-משימות, כדי להדגים את כל המצבים באפליקציה.

**שימו לב:** טעינת נתוני הדוגמה מחליפה את הנתונים הקיימים בדפדפן. כדאי לייצא קודם.
